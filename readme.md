## Descripción

Repositorio correspondiente a la materia **Programación III**, donde se recopilarán prácticas, ejercicios, proyectos y actividades realizadas durante el desarrollo de la asignatura.

Durante la materia se trabajarán diferentes tecnologías orientadas al desarrollo web, desde los fundamentos del desarrollo frontend hasta la creación de aplicaciones utilizando frameworks modernos.

## Tecnologías y conceptos

### HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para estructurar el contenido de las páginas web. Permite definir elementos como títulos, párrafos, imágenes, enlaces, formularios, tablas y otras partes de una página.

### CSS

**CSS (Cascading Style Sheets)** permite definir la apariencia y presentación de una página web. Se utiliza para trabajar con colores, tamaños, posiciones, fuentes, diseños y estilos responsivos.

### JavaScript

**JavaScript** es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento dinámico a las páginas web. Permite trabajar con eventos, funciones, objetos, datos y manipulación del contenido de una página.

### TypeScript

**TypeScript** es un lenguaje basado en JavaScript que incorpora tipado estático y otras características que ayudan a desarrollar aplicaciones más estructuradas y fáciles de mantener. Posteriormente, el código TypeScript se transforma a JavaScript para poder ejecutarse.

### NestJS

**NestJS** es un framework para Node.js utilizado principalmente para desarrollar aplicaciones y APIs en el backend. Está basado en TypeScript y utiliza una arquitectura organizada mediante módulos, controladores y servicios.

### ReactJS

**ReactJS** es una biblioteca de JavaScript utilizada para crear interfaces de usuario. Permite dividir una aplicación en componentes reutilizables y construir interfaces dinámicas de manera organizada.
